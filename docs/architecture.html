System Architecture

Filter Data Flow

User selects a filter in FilterBar.vue

4 dropdowns: Time Period (month/quarter), Location (warehouse), Category, Order Status. Each bound to a reactive ref in useFilters.js.

useFilters composable broadcasts the change

Singleton module — all views share the same selectedPeriod, selectedLocation, selectedCategory, selectedStatus refs. No prop drilling needed.

View component reacts via watch()

Each view watches the relevant filter refs. When any changes, loadData() is called. getCurrentFilters() builds a plain object: { warehouse, category, status, month }.

api.js builds URLSearchParams and fires Axios request

Non-all values are appended as query params. Example: GET /api/orders?warehouse=Tokyo&status=shipped&month=2025-03

FastAPI receives params, runs apply_filters()

apply_filters(items, warehouse, category, status) performs case-insensitive list comprehension. filter_by_month() handles plain months (2025-01), quarters (Q1-2025), and the all sentinel to skip.

Pydantic model validates response shape

Each endpoint declares response_model=List[InventoryItem] (or equivalent). FastAPI serializes and validates before sending.

Vue stores result in reactive ref, computed properties re-render

Raw data sits in ref([]). Derived data (chart series, sorted tables, KPI counts) lives in computed() — automatically re-evaluated on change, cached until stale.

Component Map

Views (Routed Pages)

Dashboard.vue KPI cards, order health donut, inventory bar chart, backlog table, top products
Inventory.vue Stock table with search, status badges, inline detail modal
Orders.vue Order status stats, full orders table with customer & delivery dates
Demand.vue Demand forecasts with trend indicators (increasing/stable/decreasing)
Spending.vue Procurement, operational, labor & overhead costs with monthly trends
Reports.vue Quarterly performance KPIs and monthly order trend charts

Shared Components & Composables

FilterBar.vue 4 filter dropdowns + reset; writes to useFilters singleton
useFilters.js Global singleton — all views share the same filter refs; exports getCurrentFilters()
useI18n.js EN/JA translations, locale-aware currency (USD/JPY), name translators
useAuth.js Current user profile, isAuthenticated flag, task list, logout()
api.js Axios client; 11 methods; builds URLSearchParams from filter objects
Modals (8) Product, Inventory, Backlog, Cost, Profile, Tasks, ProfileMenu, LanguageSwitcher
